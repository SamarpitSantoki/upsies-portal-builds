# upsies-portal-builds

HTML5 builds of [Upsies](https://upsies.samarpit.dev), a daily higher-or-lower trivia game, for game portals.

- Zips, covers and the preview video: [latest release](https://github.com/SamarpitSantoki/upsies-portal-builds/releases/latest).
- `crazygames/`: the CrazyGames build unzipped (for uploaders that take files, not archives).
  `upsies-html5-crazygames-files.txt` lists each path with its raw download URL.
